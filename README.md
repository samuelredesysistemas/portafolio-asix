Estudiante de **Administración de Sistemas Informáticos en Red (ASIX)** en Barcelona. Estoy construyendo este portafolio para documentar prácticas y laboratorios de sistemas, redes, cloud y ciberseguridad defensiva.

## Áreas de aprendizaje

- **Sistemas:** Linux, Windows Server y administración de usuarios.
- **Redes:** TCP/IP, DNS, DHCP, direccionamiento y resolución de incidencias.
- **Virtualización:** laboratorios con máquinas virtuales.
- **Cloud:** fundamentos de infraestructura y control de acceso.
- **Seguridad:** buenas prácticas, mínimo privilegio, actualizaciones y copias de seguridad.
- **Automatización:** scripting y documentación técnica.

## Cómo documento cada proyecto

Cada repositorio debe explicar:

1. **Objetivo** — qué problema resuelve.
2. **Entorno** — sistemas, versiones y topología.
3. **Implementación** — pasos y configuraciones relevantes.
4. **Validación** — comandos de prueba y resultados.
5. **Incidencias** — errores encontrados y cómo se resolvieron.
6. **Seguridad** — riesgos, medidas y datos que se han omitido.
